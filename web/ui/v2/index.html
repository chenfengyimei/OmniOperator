      B站
      
              
      
                先在配置中建立 B站通道，填写账号 UID 和独立 Cookie JSON
                凭据引用。读取会核验实际登录账号。发布只通过受管浏览器中的已核验页面控件执行，每条内容仍需「持久投递」审批。
              
      
              
              
      
                
                
                
              
      
              
      
              
      
              
      已核验的页面规则
      
              
      
                页面规则由所有者核验后保存。编辑框、提交按钮和发布记录均相对于目标容器定位。真实 mention
                必须同时配置候选 UID、编辑器组件及发布后组件；页面漂移、登录失效或挑战会停止发布。
              
      
              
              
      
                
      
                  
                  
                  
                  
                  
                
      
              
      
              
      
              
      准备发布意图
      
              
      
                使用 V2 已保存的助手消息，正文不在草稿中重复保存。mention 格式为 start、end、uid、name；范围以 Unicode
                字符计数，并须精确覆盖正文中的 @昵称。私信本批不支持 mention。
              
      
              
      
                
                
                
                
                
              
      
              
      
              
      
                
              
      
              
              
      
            
      
            
      
              
      媒体
      
              
      
                登记 B站视频或上传音视频后，可以转写音频或抽取视频帧；B站视频还可拉取在线字幕。转写文本带 [MM:SS-MM:SS]
                时间锚点；模型只能通过工具读取实际落库的内容，不接触原始视频。

      QQ 通道
      
              
      
                先在配置中建立 QQ / OneBot WebSocket 通道，并在人物中绑定发送者的 QQ 账号。群聊仅响应对当前账号的
                @。私聊和群聊分别授权、分别设置人设；不使用所有者档案、私人记忆或工具。

      持久投递
