                工具
                  QQ 扫码登录
                  用手机 QQ（机器人小号）扫码并确认登录。
                  二维码约 2 分钟自动刷新，弹窗每 5 秒自动取最新。
                  内置终端（PowerShell）
                  每个终端按钮会开一个独立会话；关闭弹窗即结束该会话。
                  安卓手机（看屏 + 点击）
                  点击屏幕任意位置即下发点击（自动换算真实分辨率）。
                  UI 树（观察用；小鱼用 tap_element 走的同一份索引）
