                  人设
                  
        
                  昵称与行为设定。改完保存，新对话即刻生效。
                  
        
                  
        
                  
      
                  
      
                  
        
                  模型
                  
        
                  LiteLLM 模型串（provider/model）。「测试」按钮会真实调用一次验证连通性。
                  
        
                  
        
                  
        
                  
      
                  
      
                  
        
                  记忆与自省
                  
        
                  记忆的容量与节奏：历史送多少、工具循环几轮、review 的强度。
                  
        
                  
          
                  
          
                  
        
                  
        
                  
        
                  
          
                  
          
                  
        
                  
        
                  
          
        
                  
      
                  
      
                  
        
                  B站与转写
                  
        
                  B站 Cookie 决定字幕/音频流能否拿到；ASR 负责无字幕视频的语音转写。
                  
        
                  
        
                  
        
                  
        
                  
        
        
                  
        
                  
          
                  
          
                  
        
                  
      
                  
      
                  
        
                  浏览器
                  
        
                  写操作（点击/输入）全部走确认流 + 每日写预算，防失控。
                  
        
                  
        
                  
          
                  
          
                  
          
                  
        
                  
      
                  
      
                  
        
                  QQ
                  
        
                  白名单外静默忽略；群里必须被 @ 才回应。改完到服务面板重启 QQ 通道生效。
                  
        
                  
        
                  
        
                  
        
                  
        
                  
        
                  
      
                  
      
                  
        
                  定时任务
                  
        
                  到点自动执行并投递；也可以直接对小鱼说"每天早上八点给我发B站日报"。心跳进程（omni-heartbeat）需在运行。
                  
        
                  
          
                  
          
                  
          
                  
          
                  
        
                  
        
                  
        
                  
          
                  
          
                  
          
                  
          
                  
        
                  
        
        
        
                  
        
                  任务列表
                  
        
                  
        
                  执行历史
                  
        
                  最近的任务执行记录（成功与失败都记账，滚动保留 200 条）。
                  
        
                  
        
                  待投递（QQ 掉线时任务结果不丢）
                  
        
                  QQ 未连接时任务结果进入队列，心跳恢复后每分钟自动补投；「发送结果未知」的条目不会自动重发——手动重试有重复发送风险，先确认对方没收到再点。
                  
        
                  
      
                  
      
                  
        
                  模型用量与费用
                  
        
                  每日额度保护钱包：超限会在发请求前被拦。金额为 0 或 null 不是一回事——null 表示这笔算不出来（单价未知），按保守记账。
                  
        
                  
        
                  按用途汇总（最近 7 天）
                  
        
                  
        
                  最近调用流水
                  
        
                  
        
                  模型能力声明（能力不声明就不放行）
                  
        
                  
      
                  
      
                  
        
                  MCP 外部工具
                  
        
                  本地 stdio 服务接入的外部工具：用户配置的只读白名单自动放行，其余一律人工确认——服务自报的"安全"标注不作数。「查看工具」会真实启动该服务做一次只读发现。配置方法见 docs/MCP.md（config.yaml 的 mcp 段）。
