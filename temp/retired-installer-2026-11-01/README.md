# 废案：一键图形安装器（2026-11-01 退役）

> **状态：已废弃，不再维护，不随主流程测试。** 代码原样保留供追溯与回滚参考。

## 为什么废弃

产品取向改变：不再提供「双击即装的图形安装器」，改为**基于开源源码的标准安装路径**——
`uv sync` → 配置 → 启动。理由：

1. **开源仓库的信任成本**：图形安装器要替用户下载 uv / Python / Chromium / NapCat / ADB，
   用户无法逐项确认，与「可控、可审计的本地 agent」定位冲突。
2. **维护成本高、覆盖面窄**：WinForms + PowerShell 5.1 + Runspace/Timer 的界面代码几乎无法单测，
   而每一步的系统状态（已装 uv？有 Python？网络是否被墙？）都要单独兜底。
3. **uv 已经解决了大部分问题**：`uv sync --frozen` 自身就负责解释器与依赖，
   安装器的价值主要剩「可选组件下载」，而这些组件本就该由用户在文档指引下自行安装并确认。
4. **可验证性**：源码安装的每一步都能被用户看见、被 CI 覆盖；图形安装器不能。

## 保留了什么

| 文件 | 说明 |
|---|---|
| `install.bat` | 原仓库根的双击入口，指向 `install_gui.ps1` |
| `install_gui.ps1` | WinForms 图形界面（步骤清单 + 彩色日志 + 代理/镜像/仅核心选项 + 后台 Runspace） |
| `INSTALLER.md` | 原安装器手册（步骤、网络策略、失败降级、手动方案） |

## 没有跟着废弃的部分（仍在 `scripts/`）

- `installer_lib.ps1`——共享实现。**`start.bat` / `start.ps1` 依赖其中的 `Start-Workbench`**
  （启动工作台并自动打开未过期的配对链接），这部分仍然有效，故保留。
  其历史注释里提到"被三个前端 dot-source"，现在只剩 CLI 安装与启动两个。
- `install.ps1`——命令行安装（同一套逻辑的 CLI 形态），保留作为不想用图形界面的辅助入口；
  README 主推的是源码安装步骤。
