# 视频理解：分镜图（D33）

> 我们能读字幕、能读评论，但**看不到画面**。这个能力域把视频变成一张
> 「能看、能引用、能回看」的宫格图——多模态模型一次看完整个视频的画面脉络，
> 而且能精确说出"第 5 格是 3:29 那里"。

学习来源是 `dsh-video-storyboard`（Apache-2.0，社区项目，与 DeepSeek 官方无关）。
**只取算法与设计，不抄代码、不抄取流层**：它依赖 ffmpeg + yt-dlp + cookies.txt，
我们走自己的 B站 WBI 直链 + 已装的 PyAV，**零新增外部依赖**（不装 ffmpeg 也能跑）。

## 两个工具

| 工具 | 做什么 |
|---|---|
| `video_storyboard` | 全片 → **一张**宫格图（存产物库）+ 一份可寻址索引 |
| `video_zoom` | 按时间码回到原始流取一帧大图，放大看某格的细节 |

两者都在 toolset `video` 下，只读、SAFE。产物走 ArtifactStore，
模型通过 `_attach_images` 真正看到这张图。

## 宫格图长什么样

```
┌────────────┬────────────┬────────────┬────────────┐
│#1 00:00-00:02│#2 00:02-00:04│#3 00:04-00:06│#4 00:06-00:08│   ← 每格烧编号与时间码
│  [画面]    │  [画面]    │  [画面]    │  [画面]    │
├────────────┼────────────┼────────────┼────────────┤
│#5 ...      │#6 ...      │            │            │
└────────────┴────────────┴────────────┴────────────┘
 台词时间轴（左→右对应视频时间）                            ← 底部一条与画面同时间轴的台词带
```

- **每格 = 一个镜头**，格边界落在真实剪辑点上；
- **格号 + 绝对时间码**烧在画面上，模型能说"第 5 格是 3:29 那里"；
- **底部台词带**把该段说过的台词按时间贴到对应位置（不做音频包络——那要单独出一张图、
  多花一份视觉 token，还丢了对齐）；
- 结果文本里附一份**机器可读的索引**（格号 / 起止 / 取帧时刻 / 字数 / 原文），
  人可以对着时间码回看原片复核。

## 怎么用

```jsonc
// 先看全片画面
{"tool": "video_storyboard", "target": "BV1xx411c7mD", "cells": 12}

// 看某一格的细节（at 取索引里的"取帧"时刻）
{"tool": "video_zoom", "target": "BV1xx411c7mD", "at": 189.0}

// 顺带把台词挂到各格（会额外跑一次本地 ASR，较慢，默认关）
{"tool": "video_storyboard", "target": "BV1xx411c7mD", "with_transcript": true}
```

## 里面是什么算法

| 环节 | 做法 | 为什么这么难 |
|---|---|---|
| 切点检测 | HSV 三通道差 + 亮度归一 + **绝对分数 35 + 局部突起量**双门 | 只看亮度漏掉「同亮度换色」；分数倍数法（3×p95）在快剪上把阈值推进刀带里，一个切点都找不到；渐变分数连续（每帧 5-11 分），真刀是 42-127 分的突变 |
| 格位分配 | **局部剪辑率积分**的等分点，只决定「合并哪些镜头」 | 均匀切会让「6 秒 20 刀」和「20 秒空镜」拿到一样的空间；格边界必须取真实切点，否则索引核不上时间码 |
| 取帧 | 段内取 3 个候选，比 Laplacian 方差取最锐 | 模糊**不改变**直方图，按直方图挑帧会心安理得地选中一张糊画面 |
| 扫描 | 流式打分，内存恒定 | 一次性收全片小帧（10 分钟片子 12fps 约 50MB）撑不住。**帧率按片长自适应抽稀**——宁可稀也不截断（真机实测截断会让长视频后半段画面整段消失） |
| 渲染 | 固定宫格 + 中文字体 | PIL 默认位图字体没有 CJK 字形；找不到系统中文体就只画轴不画字 |

## 现在的状态（2026-11-01 真机验收后）

真机跑过了——用两个真实 B站视频（34 分钟的动画歌集 `BV1xx411c7mD`、
4 分钟的口播 `BV15vxc6bEZz`），匿名态、无 Cookie。**撞出四个缺陷，全部已修**：

| 缺陷 | 真机症状 | 修法 |
|---|---|---|
| **ASR 把 PyAV 的对齐填充当样本写入** | 34 分钟音频容器 2055 秒 → 解出 **2498 秒**，多 426 秒垃圾字节。whisper 收到污染输入后输出整屏 "You You You" 幻觉，时间戳飘到 2504 秒（超出视频总长） | 按 `af.samples * 2` 精确截断。修复后同一素材输出 143 段连贯中文，时间戳 0.0–241.3 秒（视频 247.1 秒） |
| **扫描帧数上限让长视频后半段整段消失** | 34 分钟视频只覆盖前 800 秒（**39%**），后 20 分钟画面全丢；末格还横跨 22 分钟未扫描区（索引里的时间码在撒谎） | 帧率按片长自适应抽稀，保证 100% 覆盖；上限提到 30000 帧。代价：扫描 7s → 18.2s（仍 100× 实时以上），内存恒定 |
| **下载没有重试也没有断点续传** | 55MB 视频下载中断过一次（收到 10MB 就断），残缺文件留在磁盘上——而容器元信息照样报出正确时长，**看着像成功了** | 加 Range 续传 + 重试；服务端忽略 Range 时丢弃旧数据重写。实测续传后文件与完整下载逐字节一致 |
| **ASR 模型已缓存却强制联网校验** | 模型明明在本地缓存里，但 HuggingFace 校验走代理 502 → 整个 ASR 不可用 | 先 `local_files_only=True` 离线加载，失败再联网 |

### 多模态实际效果（已验）

DeepSeek（`deepseek/deepseek-flash`）真看这张宫格：

- **能读出编号与时间码**：问第 7 格的时间码，答 "06:34-07:50"——与索引真值一致；
- **能说清行列与画面内容**：答 "3 行 4 列"、第 3 格 "银白长发、穿蓝白红配色服装的女性角色"——与肉眼一致；
- **视觉 token 成本**：1300×622 的 PNG 原图 / 半尺寸 / JPEG q85 **一律 742 tokens**
  （DeepSeek 按固定网格算，与字节数无关；纯文本基线 34 tokens）。
  换句话说：**缩图省不了 token，只省磁盘**——所以我们不缩。

### 性能实测（34 分钟视频）

| 环节 | 耗时 | 备注 |
|---|---|---|
| 下载 | 58.6s | 55MB，约 0.94 MB/s |
| 流式扫描 | 18.2s | 100× 实时以上，内存峰值 1.2MB（恒定） |
| 切点检测 | 0.02s | 检出 64 刀 |
| 取最锐帧 | 1.9s | 12/12 格 |
| 渲染宫格 | 0.15s | 1300×622，856KB |
| 单帧放大 | 0.11s | 精确到请求时刻（900.00s） |
| ASR 转写 | 316.7s | 6.5× 实时，CPU int8 small 模型 |

### 仍然存在的限制

1. **官方 B站字幕没有时间戳**，对齐只能靠本地 ASR（CPU 上 34 分钟音频要 5 分钟）；
2. **ASR 质量受模型档位限制**：`small` 档在快速中文口播上会出错字，需要 `medium` 才更准
   （但 CPU 上慢 3-4 倍）；
3. **多模态验证只跑了 DeepSeek**：配置里的 `vision: anthropic/claude-sonnet-4-5`
   **当前没有可用密钥**（`.env` 里 `ANTHROPIC_API_KEY` 为空），换 Anthropic 需要另配；
4. **扫描抽稀的极端情形未验**：超过 42 分钟的片子会抽到 12fps 以下（本机没这么长的样本）；
5. **产物只支持 PNG**（宫格本就是 PNG，暂不需要 `video/*` mime）。

## 架构位置

```
tools/storyboard/          引擎（不认识任何平台）
├── detect.py              切点检测（纯逻辑，零 I/O）
├── segments.py            格位分配 + 台词挂载 + 可寻址索引（纯逻辑）
├── decode.py              PyAV 解帧 / 取最锐帧
├── render.py              宫格渲染 + 台词时间轴带
├── source.py              取流 Protocol（跨域引用的禁令逼出来的设计）
└── tools.py               工具注册

tools/bilibili/video_source.py   平台适配器（实现 Protocol）
bootstrap.py                      唯一组装根：把两者接起来
```

`tests/test_arch.py` 禁止 tools 域之间互相引用，所以分镜域**不能** import B站域；
取流能力用 Protocol 注入，由 `bootstrap.py` 接线。以后接 YouTube 或本地文件，
只加一个适配器，引擎一行不用改。
