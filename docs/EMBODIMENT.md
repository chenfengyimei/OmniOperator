# 数字具身（D32）

> 设置中心里的「数字具身」分类：把 agent 现在真正"身处"的平台收在一起，
> 让人一眼看出它能干什么、还差什么。当前四个：**哔哩哔哩 / 浏览器 / 手机 / QQ**，
> 外加一张总览卡（`数字具身总览`）。

## 为什么单独立一个分类

以前这四个平台散在「工具与设备」和「平台与通道」两组里：安卓控制混在终端旁边，
B站与浏览器混在服务与运行旁边。对使用者来说这不是分组问题而是**心智模型**问题——
"这个 agent 到底活在哪些地方"应该是设置中心的第一个问题，而不是散落在四个角落的四个开关。

现在侧栏固定六组（`agent/tests/test_ui_hub_sections.py` 守卫）：

| 组 | 分区 |
|---|---|
| 核心系统 | 上下文系统 / 技能系统 / 记忆系统 |
| 对话与模型 | 人设 / 模型 / 压缩与复盘 |
| **数字具身** | **数字具身总览 / 哔哩哔哩 / 浏览器 / 手机 / QQ** |
| 工具与设备 | 人工终端 / 后台任务 / MCP 服务 / 插件 / 能力诊断 / 项目索引 |
| 平台与通道 | 服务与运行 / 定时任务 |
| 文件与用量 | Agent 与文件 / 花费 / 扩展能力 / 关于 |

「数字具身总览」只读本地状态（配置、凭证文件、adb 是否在 PATH），**不联网**；
每个具身的状态与缺口都写成人话，例如"未配置登录凭证：只能看公开内容"。

## 四个具身各自能做什么

### 哔哩哔哩

账号、视频画面、评论与发布都归它，细则见 [BILIBILI_WRITING.md](BILIBILI_WRITING.md)。

- 读：视频信息、字幕（没有就本地 ASR 转写）、**抽帧拼成一张长图**直接给多模态看画面、
  评论（热门/最新、可翻页）、楼中楼回复、用户搜索（拿 UID）
- 写：发布评论、回复某条评论（目标带 `?reply_id=`）、私信回复、艾特
  ——**每一次都要人工确认**：先存草稿（全文与艾特清单摆给人看），批准后只提交一次并回读

### 浏览器

持久登录态的 Playwright。读（打开/读页面/截图）SAFE；写（点击/填表）CONFIRM，
每天有写额度（`browser.max_writes_per_day`）。B站的发布就是走它的页面 UI，
不走 B站私有写 API。

### 手机

ADB 通道：看屏幕、点元素、划滑块、输文字、拉 UI 树。动作绑定观察令牌
（点之前复核界面、点之后强制复检），真实设备尚未验收。

### QQ

OneBot v11 通道：私聊/群聊（群里被 @ 才回）、主动提醒（有额度与安静时段）、
投递 outbox（掉线不丢结果）。空白名单 = 谁都不许。

## 接口

| 接口 | 作用 | 是否联网 |
|---|---|---|
| `GET /api/system/embodiments` | 四个具身的就绪状态与能力清单 | 否 |
| `GET /api/system/bili-account` | B站当前登录账号（UID/昵称/等级） | **是**（B站 nav） |

账号接口是设置中心里唯一会外呼的接口，**必须由人点「检查登录状态」才发出去**，
查不到就如实报错，不缓存成"已登录"。

## 边界与剩余限制

- **艾特目前是文本 @昵称**，不是 B站网页版的真实 mention 组件。要真实艾特，
  需要用户在 `config.yaml` 核验页面上的用户选择控件后再开（见 BILIBILI_WRITING.md）。
- **抽帧拼图依赖 `av`（随 faster-whisper 安装）与 Pillow**；DASH 分片流在部分视频上
  可能解不出画面，此时工具会明说"没抽到"，不会给一张空白图。
  **已在真实 DASH 分片流上验过**（`BV1xx411c7mD`，30 分钟视频，55MB 流，6 帧等距取样拼成
  1280×1500 一张图，逐格画面与时间戳均正确）——多模态模型读这一张图就能复述整段视频的画面脉络。
- **本机没有配 B站凭证**（`data/bili_cookies.json` 不存在）：账号接口会如实报
  "code=-101 账号未登录"并给出配置指引，**不会**伪装成"已登录"；总览接口也因此显示
  「待配置」。真实账号下的读权限差异（清晰度、字幕、大会员内容）仍需配好凭证后再验。
- **工作台需重启后新接口才生效**：设置中心的静态页面从磁盘读，所以「数字具身」分组
  **立刻可见**；但 `/api/system/embodiments` 与 `/api/system/bili-account` 是启动时注册的路由，
  **未重启前是 404**（已实测确认）。此时总览卡会读失败、账号检查按钮点不动——重启工作台即可。
- 四个具身的状态都是**离线可读**的；真实设备、真实 QQ 通道的行为
  仍需在真机上验收，不能用总览卡的红绿灯当验收结论。
