## ③ 详细仓库介绍（Markdown，粘贴到 README 或「项目介绍」富文本）

```markdown
# OmniOperator · 小鱼

> **一个跑在你电脑里的数字具身智能体**
> 不是聊天框里的助手，而是有身体、有感官、有记忆、有节律、有边界的常驻数字存在。

过去两年，AI 的形态停留在**对话**：你问，它答；关掉页面，它就不存在了。

但真正的智能从来不是"会说"，而是**"在世界里做事"**。人类之所以能做事，是因为我们拥有身体——
手能操作、眼能观察、记忆能积累、生物钟能驱使我们主动行动。

**OmniOperator 把这件事搬进你的电脑。**

## 什么是「数字具身」

| 维度 | 传统助手 | OmniOperator |
|---|---|---|
| **身体**（效应器） | 只能输出文本 | 三套真实效应器：Windows UIAutomation 操作桌面应用、ADB 驱动安卓手机、Playwright 操控浏览器 |
| **感官**（观察） | 无 | 截图、UI 树、MJPEG 实时画面、网页正文、终端输出——**先看见，再动手** |
| **记忆**（连续性） | 每次从零开始 | 六层记忆：逐字记住所有对话 → 压缩成日/周/月笔记 → 重要的人立成人物卡 → 事实按需检索 |
| **节律**（主动性） | 你说它才动 | 心跳驱动：定时任务、依赖链、掉线补投——你不叫它，它也知道该干什么 |
| **边界**（可信） | 靠模型自觉 | 确定性安全内核：三档风险、fail-closed、灾难级硬黑名单——**写死在代码里，不听模型的话** |

它同时活在四个入口里——**QQ、Web 工作台、CLI、心跳进程**——共用同一个内核、同一份记忆、同一套权限。
你在 QQ 里随口说的一句话，会在工作台留下可回放的运行轨迹；你半夜睡觉时，它按自己的节律整理记忆、执行任务。

## 为什么"具身"是真问题：观察 → 决策 → 执行 → 复核

"让 AI 点一下按钮"听起来简单，做起来全是坑：

- 它点的那一刻界面已经变了——**点到了别的东西**
- 两台设备交替操作，坐标互串——**手指按在了另一台手机上**
- 进程被杀在发送中途——**消息发出去了还是没发出去？没人知道**

OmniOperator 的答案是：**给每一次动作绑定一次观察，动作必须携带观察令牌**。

```
观察（截图 / UI 树 / 设备树）→ 生成 obs=<id>，绑定当时的界面快照
决策（模型选择元素）        → 必须带着这个令牌回来
执行（锁帧，禁止动画干扰）  → 执行前复核：界面还是那个界面吗？
复核（不一致→拒绝，重观察） → 执行后强制复检：真的变了吗？
```

旧的 idx 令牌**永远不会点到新元素**；`tap_element` 不带 `obs=<id>` 直接拒绝；
桌面端有窗口租约、浏览器端有单线程所有权——同一时刻，只有一个"手"在动。

这不是模型能力的胜利，是**工程约束的胜利**：让不可靠的模型，在可靠的骨架里工作。

## 六大核心机制

### 1. 确定性安全内核：不信模型，只信代码

| 机制 | 硬约束 |
|---|---|
| **三档风险分级** | 每个工具声明 SAFE / CONFIRM / DANGEROUS；DANGEROUS 一律拒绝 |
| **灾难级硬黑名单** | `format`、`rd /s`、`del /f /s /q` 等命令**人工确认也不执行** |
| **无人值守 fail-closed** | 定时任务默认拒绝一切写操作；审批器缺省即拒绝 |
| **结果未知永不重试** | 发送中途失败标记 `unknown`，禁止自动重发——重复发送比漏发更糟 |
| **内容是数据，不是指令** | 网页/记忆里写"忽略之前的指令"也没用，权限只由风险等级决定 |
| **白名单 fail-closed** | QQ 空白名单 = 拒绝所有人；群聊不注入个人档案与常驻记忆 |

### 2. 六层记忆：像人一样遗忘与回忆

上下文窗口是有限的，人的一生是无限的。解决方案不是"更大的窗口"，而是**分层**：

- **M1 对话全量**：每一句原文，按天索引、分页读取，**永不整库进上下文**
- **M2 会话全量**：对话 + 工具过程完整流水（工具名/参数/结果/run_id）
- **M3–M5 日/周/月笔记**：分层压缩、三态认领（UNIQUE 幂等）、关机不丢
- **M6 核心人物**：人物卡（档案/常驻记忆/临时事件），owner 是全库唯一一等人物
- **语料**：事实记忆，FTS5 + sqlite-vec 向量 RRF 融合检索，带遗忘墓碑
- **注入**：常驻条目作为稳定前缀，保证缓存命中

全量负责"不丢"，笔记负责"可读"，人物卡负责"懂人"，语料负责"查得到"——四套读取协议，谁也不越界。

### 3. 跨进程账本：至多一次，不算错账

心跳、工作台、QQ、CLI 是**四个独立进程**。JSON 文件在这里必然崩坏（后写覆盖先写、损坏被当"首次启动"、两个进程领同一个任务）。

所以核心状态全部落到 **SQLite + 短事务 + 条件更新**：

- **至多一次领取**：`UPDATE ... WHERE status='pending'` 的 `rowcount == 1` 才是"我拿到了"——四个进程抢四个任务只领到两个（有测试验证）
- **微美元整数记账**：浮点累加会在几十万次调用后"账不平"，而账不平的预算等于没有预算
- **未知不是 0**：`cost_micro = NULL` 是"算不出来"，`0` 是"确定免费"，两者绝不混用
- **预留-结算**：先按输入估算+输出上界预留，事后按真实 usage 结算，超预算硬拦截

### 4. 自主节律：你不叫它，它也在做事

- **cron 调度**：周期/一次性任务，显式 IANA 时区（含 DST 缺口与重复时刻）
- **任务链**：`context_from` 绑定**具体成功 run**（prompt 带 run_id）+ 新鲜度上限，上游失败/过期就停
- **并行上限**：库内原子计数默认 2；运行中再次到期合并，不无限排队
- **掉线补投**：QQ 掉线时结果进 outbox 持久队列，恢复后补投，3 次失败成死信
- **记忆整理**：心跳每 5 分钟一轮，压成日/周/月笔记——关机不丢、幂等可重试

### 5. 可扩展边界：插件与外部能力都不能越权

- **插件系统**：manifest 校验 → 隔离区落盘（**绝不执行包内脚本**）→ 人工激活 → 命名空间注册。
  "校验零执行"是结构化的：校验模块里**没有 importlib、没有注册表**
- **技能系统**：内容指纹 CAS（冲突拒绝）、历史/差异/回滚、外来包逐文件 sha256 防篡改复核
- **MCP**：外部工具渐进发现，**schema 漂移自动撤权**（服务升级换参数形态 → 只读授权立即失效）
- **插件社区**：内置社区客户端与参考分发服务器，发布用内容哈希去重

### 6. 单内核四入口 + AST 强制分层

```
QQ 通道 ─┐
Web 工作台 ─┼─→ bootstrap（唯一组装根）→ core 内核
CLI ─┤              ↓
心跳 ─┘   tools / llm / memory / safety
```

**分层由 AST 静态检查强制**：`llm` 不许 import `memory`、`config` 是叶子层、
`Gateway/MemoryStore/Agent` 只能在 `bootstrap.py` 构造——不是文档里的"建议"，是提交就会红的硬约束。

还内置**能力档位路由**：按回合判定 chat/retrieval/agent 三档，少注入工具规格就省 token。

## 快速开始

环境：Windows 10/11（x64）· [uv](https://docs.astral.sh/uv/)（自动准备 Python 3.12）·
约 1.5 GB 磁盘 · 能访问 PyPI · 一家模型密钥或本地 Ollama。
可选：Playwright Chromium（浏览器）、ADB + 安卓机、NapCat（QQ）。

```powershell
git clone https://gitee.com/chenfengloveyuri/OmniOperator.git
cd OmniOperator
uv sync --frozen                                 # 建 .venv、装依赖（Python 3.12 由 uv 提供）
uv run python -m playwright install chromium     # 可选：浏览器 / B站能力

Copy-Item .env.example .env                      # 填模型密钥（本地 Ollama 可留空）
Copy-Item config\config.example.yaml config\config.yaml

uv run omni-web        # Web 工作台（控制台打印配对链接，点开即配对）
uv run omni            # CLI
uv run omni-qq         # QQ 通道（需 NapCat）
uv run omni-heartbeat  # 定时调度

# 装完自检
uv run --no-sync python -m omni.channels.doctor
```

> 一键图形安装器已于 2026-11-01 废弃（代码归档在 `temp/retired-installer-2026-11-01/`），
> 现在只提供源码安装路径。
