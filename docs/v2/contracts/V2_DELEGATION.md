# V2 父子 run 委派

K04 已接生产模型工具 `delegate_task`、同库持久化、独立执行与所有者只读 API。当前交付是**单层、有界、等待汇合的委派**；整个 Agent 对标和 V2 尚未完成。验证范围见 [证据](../../evidence/v2-delegation.json)，后续功能见 [内核对标](V2_AGENT_CORE_PARITY.md)。

## 调用与边界

只有所有者入口的 agent 档模型回合可使用此控制工具，受当前 disabled_tools 限制；chat、QQ 和子 run 不暴露它。生产组装默认启用；注入自定义 capabilities 的调用方默认关闭，可用 `delegation_enabled=True` 明确启用。

单任务示例：

```json
{"goal":"检查当前方案的边界","context":"只分析提供的资料","max_calls":4,"budget_micro":100000}
```

批量示例：

```json
{"tasks":[{"goal":"核对接口合同"},{"goal":"核对来源删除行为","max_calls":3}]}
```

`tasks` 不能与单任务字段混用；整批在一个事务中创建，任一项无效则整批回滚。父 run 暂停自身模型循环，等待这一批真实执行任务结束，按输入顺序返回结果。子任务批次并行不等于 K05 的通用工具批次并行。

| 项目 | 当前上限/行为 |
| --- | --- |
| 深度 | 1；子任务不能继续委派或切换档位 |
| 子数 | 每个父 run 生命周期合计 4 个；每批 1–4 个 |
| 调度 | 根任务沿用现有容量；额外独立子任务池最多 4 个，排队不占实际任务容量 |
| 输入 | goal 非空、最多 4000 字符；context 最多 8000 字符；拒绝 NUL、代理字符和额外字段 |
| 模型调用 | 每个子任务 1–8 次，默认 4 次；仍受原 max_steps 及上下文预算限制 |
| 子预算 | 1–1000000 微单位；默认 min(1000000, 原单次预留×max_calls) |
| 家族预算 | 父与全部子任务合计最多 1000000 微单位，且不超过父捕获的非零每日限额；最多 64 次已发送/待结算模型调用 |
| 返回 | 成功孩子的最终 assistant 文本；单任务最多 4000 字符，批次摘要字符总额最多 4000，显式标注截断 |

费用沿用原共享每日账本；子预算不新增额度。调用前以结算费用与待结算预留校验，调用后先持久结算真实费用再检查实际超支；超支可阻止后续工作，不能撤销供应商已经产生的费用。unknown 预留继续持有，不重试为免费调用。

## 上下文、授权与来源

每个孩子有独立 session、run、work item、上下文快照和 session 租约，`runs.parent_id` 与不可变 `run_delegations` 绑定原父 run。父会话 FIFO 保持；父任务占满根容量时孩子仍可被独立池领取。

孩子继承父 run 捕获的 settings/model revision、授权 epoch 和策略版本；只使用固定模型，不接受模型/provider 参数。工具集合来自发起委派的真实父模型调用清单，以 wire schema 摘要约束；新增工具不能进入，已改变或丢失的工具拒绝启动。技能、扩展和 MCP 复制父任务已审捕获，不重捕获较新的权限；先复制目录再封存 epoch，撤权仍阻断下一次使用。

孩子读取父快照的精确记忆修订，并有自己的目标/上下文消息；不复制父任务的全部对话与中间工具轨迹。生成的目标/上下文只是任务数据，不能授权写动作，也不能直接成为模型写入长期记忆的来源证据；可以引用真实原消息、已观察文档范围或实际成功动作。父 run 只收到最终有界摘要、状态、错误码、已知费用与未知调用计数。

每个子任务中的外部写动作继续走实际观察、独立 action、原审批和逐次派发链，审批属于孩子；委派控制本身不伪造一个外部写动作。Agent/模型禁用、来源删除、父状态、租约和策略失效均阻止后续发送或派发。父或子来源删除传播到相关会话并清除摘要投影、任务清单和派生记忆依赖。

## 取消、unknown 与恢复

父取消/关闭/异常向所有孩子传播，取消等待保持真实 Task 的归属，直到孩子的模型/worker/资源清理完成才结束父 run 和释放父租约。实例关闭超时如实保留待清理项；不因数据库先终态就认为真实任务已结束。

任一孩子产生 unknown 外部动作，父任务停止，批内其余孩子取消并实际汇合；原动作保持 unknown，不自动重发，也不再用父模型文本将它改写为成功。普通子失败以有界错误结果返回父循环。供应商费用 unknown 与外部动作 unknown 分开记录。

独占启动恢复将所有仍活跃的委派孩子标为 interrupted，包括尚未领取的孩子，不自动重放；模型未知预留、动作未知状态与原恢复账本保留。正常重启不是重新授权原委派。

## 持久化与所有者查看

迁移 `v2_0042` 新增 `run_delegations`、同 Agent 外键、数量/深度/来源约束与不可变触发器。原 `v2_0041` 及更早迁移不改写。测试仅升级隔离数据库；本批未停止或升级实际 Windows 服务数据库。

`GET /api/v1/agents/{agent_id}/runs/{run_id}/delegations` 通过原所有者认证返回直属孩子结果；跨 Agent 404，写方法不开放。来源失效后摘要返回空串并标 `summary_redacted`，不改写历史 run 的实际终态。暂无新增委派管理 UI。

此批没有跨层嵌套、异步委派 handle/reconnect/steer、自选模型、Android 专用视觉子代理或通用工具并行。相关参考扩展继续留 K10/K13/K14 等未完成任务，不能把本批当作全部参考功能对等或整体验收。
