# V2 所有者空间管理

单实例仍只有一个所有者。`POST /api/v1/agents` 创建独立Agent空间，`GET /api/v1/agents/{agent_id}` 读取元数据，`PUT /api/v1/agents/{agent_id}` 使用 `{name, revision}` 重命名；全部沿原所有者鉴权，不向模型开放空间管理。

创建复用原仓储初始化：独立默认模型配置、设置、档案和历史范围，不复制当前空间的消息、记忆、工作目录、凭据引用或工具权限。应用层在同一写事务中检查最多64个空间并创建，防止并发越过容量；仅显示名相同不会合并空间。名称最多100个Unicode字符，要求非空、合法UTF-8且不含控制字符，不正规化原文。

重命名按Agent修订号CAS；旧修订409拒绝，原名称保持。无变化且修订匹配时不增加修订或重复审计；名称变更不修改设置、会话、配置、权限或空间UUID。创建/重命名审计只登记操作与修订，不再复制名称正文。当前入口不提供删除或停用，不从名称变化推导撤权。

工作台通过“新建空间”“重命名空间”显式操作。创建成功后切换空间并沿原初始化清空旧显示；重命名冲突保留本机名称草稿，重新打开时先显示服务器当前名称和修订再确认。连接或空间代次变化后丢弃迟到回执。写请求没有自动重试；响应丢失时提示先重新连接核对，已确认创建但列表刷新失败则明确告知，避免自动重复创建。

开发优先，验证仅覆盖受影响模块和调用方；整个V2开发完成后统一全量。真实平台验收、账号和长期稳定性状态不因此改变。
