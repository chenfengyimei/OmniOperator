# K16 长片场景切点与槽位设计合同

2026-11-23 · status: design_contract_recorded · 纯文档，未改源码/HTTP/迁移。

依据真实素材验收（Big Buck Bunny，596.48s，CC-BY 3.0）结果：[V2_K16_REAL_ACCEPTANCE](V2_K16_REAL_ACCEPTANCE.md) / [v2-k16-real-acceptance.json](../evidence/v2-k16-real-acceptance.json)。

## 0. 已复现的问题

| 问题 | 证据 | 影响 |
|---|---|---|
| P1 长片采样不足 | 240 样本=2.46s 间隔；30 个代表切点只召回 4/30 | 长片场景合并、帧窗口跨多个镜头 |
| P2 提采样后运动误切 | 1200 样本召回 26/30，但 117 切点；抽查 45.04s 同场景误切 | 不能简单把 `SCENE_MAX_SAMPLES` 从 240 提到 1200 |
| P3 强切点绕过过分割 | raw score≥24 绕过尖峰守卫 → 135 切点（约 2.5s/个），已回退 | 不能只按分数阈值放宽 |
| P4 credits 占槽 | 240 样本 1/12 帧为 credits；1200 样本 5/12 | 240 槽位不是主要问题；1200 采样后段偏多 |
| P5 宫格/字节非瓶颈 | 1280×2280/3.51MB，未越 8192/16M/8MiB | 自适应宫格不是本次优先项 |

## 1. 决策门（D0–D5）

| 决策 | 选项 | 建议 |
|---|---|---|
| D0 默认采样 | (a) 保持 240；(b) 600；(c) 1200；(d) 两遍（低采样初筛+高采样复核候选） | 暂保 240，待 D1 有运动判别后评估 (d)；单改 (c) 已证运动误切 |
| D1 切点判别 | (a) 当前 HSV+尖峰；(b) raw strong 绕过（已否）；(c) 直方图/边缘差 + 0.5s 前后帧投票；(d) 运动补偿/光流；(e) 学习模型 | 先做 (c) 的离线评测，再决定是否实现 |
| D2 槽位分配 | (a) 当前按时长；(b) 时间等分覆盖；(c) 每段槽位上限；(d) credits/静态文本分类 | 240 仅 1/12 credits，暂不改槽位；(b) 单独实验把 240 credits 从 1→2、内容 11→10，已回退 |
| D3 评测 | 30+ 人工标点、precision/recall、锚点偏差、耗时/RSS、credits 占比 | 必须先扩标注，不能只用 10 点 |
| D4 接口 | 内部算法；不改 HTTP/表/迁移 | 不改共享接口，A 无需介入 |
| D5 回滚 | 保留 240/固定 2 列开关或提交回滚 | 默认行为变更必须可回滚 |

## 2. 建议最小批（批准后）

1. **扩标注**：同一素材标 30–40 个切点（含快切、渐变、credits 边界），另加 1 条真实长片（若所有者提供）。
2. **离线评测**：对 240/600/1200 采样 × 当前 HSV+尖峰、直方图/边缘差+前后帧投票，统计 precision/recall/偏差/耗时/RSS；不先改生产。
3. **槽位实验**：当前 vs 时间覆盖 vs 覆盖+每段上限，统计 credits 占比与内容覆盖；用同一批帧人工打分。
4. 选择同时满足 recall/precision 与资源预算的方案，再实现 domain/worker 最小改动 + 固定素材回归。
5. 通过后更新合同/证据；未达标则保持默认，不盲目调阈值。

## 3. 明确不做

- 不直接把 `SCENE_MAX_SAMPLES` 提到 600/1200；不恢复 raw strong 绕过。
- 不改自适应宫格/DP（宫格未越限）、不引入 OCR（依赖未批）。
- 不改 HTTP/表/迁移/CI；不新增模型或外部二进制。

## 4. 完成条件

30+ 标点下切点 precision/recall 达标（建议各 ≥0.8，容差 ±1.5s）、credits 占槽显著下降、240 默认耗时/RSS 不越预算，且既有 33 项 scenes 与 422 项 K16 入口无回归，才可改默认；否则保持 240 并在合同记录原因。
