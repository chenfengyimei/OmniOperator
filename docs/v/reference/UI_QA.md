## 已修复问题与操作

| 触发 | 修复与验证 |
|---|---|
| 读取任务 A 日志时切换 B，A 迟到返回 | 选中版本和请求取消隔离；不改写 B 的日志与续读位置 |
| 终端 A 读取剪贴板时切换 B | 粘贴绑定原视图与连接，目标变化即取消；多行粘贴再次确认 |
| A 回合等待期间切换 B | 回复、进度与取消绑定发起会话；不切回 A，不向 B 插入 A 的费用或错误 |
| 中文输入法确认候选词 | composing Enter 不发送；普通 Enter 发送，Shift+Enter 换行 |
| 聊天网络失败 | 保留草稿，提示请求可能已执行；不自动重发 |
| MCP A 目录迟到、用户已查看 B | 版本与 AbortSignal 隔离；旧目录不能覆盖详情或提供错误授权按钮 |
| 安卓未选设备、无观察或动作执行中 | 禁用不具备前提的操作；观察来源与执行中状态明确展示 |
| 窄屏主页面堆叠多个固定高度面板 | 单区域切换保留完整聊天宽度；各专题支持手机宽度 |

后台任务提供命令/任务/会话搜索、执行状态筛选、元数据、中文状态、取消确认、跟随输出和复制。
输出仍有界保留，缺失明确提示；进程完成不证明外部业务目标完成。
人工终端断连按 1/2/4/8/15 秒有界恢复，失败后手动重新连接；恢复不重发键盘输入。
自然退出会话仍回放已保留输出与退出码。无依赖/无会话时展示操作指引。
MCP 保留诊断原始数据、完整目录逐工具展开、分页一致性复核和指纹确认；写操作失败不重放。
安卓页无自动探测，预览不授权动作；操作后重新观察，失败继续提示副作用可能未知。

公共请求默认读超时 15 秒、写超时 60 秒，对话保留服务端回合生命周期，不额外截断长回合。
超时不代表副作用未发生。401 提示重新配对，422 只展示字段和错误，不回显输入值。
