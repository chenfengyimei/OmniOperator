# 设置中心：上下文统计与配置

工作台设置中心的“上下文”页集中展示窗口用量、缓存样本、提示词结构和相关配置。侧栏“上下文统计与设置”可直接进入。人设与模型、回合后整理和审批仍有各自设置页，页内提供跳转入口。

## 可查看的信息

- 当前工作台会话、模型、声明的上下文上限；未声明时显示未知，不假设模型容量。
- 保留窗口的估算 tokens，分为固定提示与消息开销、工具规格、动态快照、对话与摘要。
- 会话消息总数、实际保留条数、快照数、旧消息无快照数、摘要版本与覆盖区间。
- 固定提示词全文、system 与工具定义的 SHA-256；不展示私人笔记、档案、人物卡或历史正文。
- 当前会话最近 100 条有记录的主对话模型结束事件的缓存用量。命中率只用同时上报输入 token 与缓存读取 token 的完整样本计算；未上报保持未知，真实上报 0 才显示零命中。压缩、Review 和未记录的调用不在这个样本窗口内。

估算针对已有保留窗口，不包含下一条用户输入、新快照、在途工具结果或图像，也不是供应商计费数据。只读预览复用内核渲染，不压缩、不保存摘要、不取新时间、不调用模型。常规 `/api/state` 与本页使用同一估算来源，完整固定提示仅在上下文专用接口返回。

## 可调整的配置

| 分组 | 设置 |
|---|---|
| 历史与执行 | 历史消息上限、每回合工具循环上限 |
| 压缩 | 自动压缩开关、触发预算、保留消息数、最低消息数 |
| 记忆注入配额 | 常驻笔记字符上限、单条事实字符上限、每日记忆写入限额、检索资料标识 |
| 自动整理配额 | 等待队列容量、所需新消息数 |

压缩触发值沿用 `compression.trigger_chars` 的字符预算声明，内核按约 2 字符/token 换算并计入消息/工具开销。页面同步显示换算值。保留数为 0 仍保护当前请求、当前快照和完整工具调用。每日记忆写入限额为 0 表示禁止写入。

压缩判定使用消息估算，包含消息及工具调用/结果开销；工具定义在窗口总估算中单列，不纳入压缩判定。窗口总估算超过触发预算时，不一定立即生成摘要，还需满足最低消息数等条件。

这些配置保存到正在使用的 config.yaml，**重启相应入口后生效**；当前回合不热切换。页面同时显示已保存值和运行值，并提示是否待重启。历史与工具步数从原“记忆”表单移到这里，避免两处表单互相覆盖。原“记忆”页继续设置自动整理开关、回看条数、整理步骤与审批档。

参数归当前入口加载的配置文件；多个 Agent 或入口共用同一配置文件时也共享这些参数。会话统计和记忆资料仍归当前运行空间，页内不会切换或合并其它 Agent 的数据。

配置写入使用白名单、数值校验、跨进程文件锁、原子写和 revision CAS。其它设置页修改过同一配置文件后，旧版本保存会被拒绝，草稿保留，可用“重新读取配置”确认后重载。普通设置写入也共用该锁，避免覆盖并行页面的新值。未知字段、越界数值、外部 Host/Origin 与未配对请求拒绝。

本页不添加供应商专属 cache_control 或 TTL 参数，也不改变模型价格和费用结算。提示词布局的缓存保证及边界见 [PROMPT_CONTEXT.md](PROMPT_CONTEXT.md)。

## 开发入口与验证

请求失败必须结束所有加载占位：当前会话、窗口用量和缓存区显示暂不可用，清除旧的分布与提示词预览，保留“刷新统计”和页内“重试统计”。重试成功后恢复统计；失败不能当作零样本。404 `Not Found` 提示重启工作台服务后刷新，404“会话不存在”则保留原意，避免把删除会话误报为接口版本问题。设置读取与会话统计独立，统计失败不影响已读到的设置。

2026-10-31 现场核查：已配对的本机工作台 `/api/state`、`/api/context`、`/api/context/settings` 都返回 200，当前会话有历史与供应商缓存样本；未复现接口仍缺失。已复现并修复的是前端失败后其它区域一直停留“正在读取”的状态问题。若再次出现 404，应检查浏览器请求的地址/端口与正在运行的服务，不能仅凭页面文案认定当前后端仍旧。

- `core/agent.py::context_overview` / `core/compress.py::preview_context`：只读统计与保留窗口渲染。
- `memory/runs.py::context_cache_usage`：按会话聚合有限缓存样本，不返回事件正文。
- `system/config_io.py`：配置快照、文件锁、CAS、白名单校验与原子保存。
- `channels/web_api/context.py`：`GET /api/context?session_id=`、`GET /api/context/settings`、`PUT /api/context/settings`。
- `web_static/ui/app/hub-context.js`：独立设置域，使用现有 OmniUI、委托动作与公共组件。请求按会话和版本隔离；刷新统计不覆盖未保存的配置。
