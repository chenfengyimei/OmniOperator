# OmniOperator UI V3 产品规格

2026-11-27 · 已选 A Precision Workspace

> 让人物在数字具身中真实地生活。

OmniOperator 是常驻本地、具有自主能动性的数字具身智能体，以拟人情感为核心，借助记忆、节律、感知及受授权的行动参与日常生活。用户从自然的交谈发起请求，主 Agent 理解语境、调度能力、交付能直接使用的成果。界面优先讲清楚能做什么、做成了什么、哪些决定需要用户参与。人设与表达依照实际 Agent 配置，情感通过称呼、语境和持续的交流表现。

## 工作台

- 左边并排保留工作区和会话栏。工作区直接进入主会话、工作进展、Worker 协作、任务、审批和工具与文件。用自然语言标题找回当前和历史对话。指令从唯一的主会话发出。
- 中间是人与 Agent 的交流。把用户意图、Agent 回复、明确的待确认事项放在阅读路径上。动作的结果通过实际回执呈现。
- 右边是产物。优先展示当前会话交付物的名称和正文，支持切换及打开完整内容。未生成、加载失败和有成果分别表达。
- 工作进展提供用户按需查看的进度、任务和具体执行证据。技术字段进入需要它们的详情。
- 窄屏以交流为主，使用可见文字入口打开会话或产物。关闭后恢复焦点与草稿。

## 表达原则

工作台的产品名称、开屏信息与设置统一使用 OmniOperator。Agent 签名读取所连接实例的名称。本地预览明确标记「本地演示」与「演示会话」，用晚间回顾、整理资料和准备待办说明常驻协作的使用方式。提示语说明对象与可采取的下一步。Agent 说已经完成的事必须有实际证据，写入、发送或其他需要授权的动作沿用实例权限。对尚未掌握的时间与影响使用明确的不确定表达。

视觉以 A 的纸白、暖墨和柔和强调色为基础。会话可读性与成果正文优先。产品标语用于产品介绍和会话空状态，常用工作空间保留实际内容和可操作入口。
