# WorkWeb 设计系统 V1

从 [产品规格](PRODUCT_SPEC.md) 和确认的 [A 方向](DESIGN_DIRECTION.md) 派生，当前覆盖会话、产物、工作进展与连接设置。

- 颜色以 WorkWeb/ui/tokens.css 为准。沿用初版 A 深浅主题的暖纸、墨色与青绿。顶栏与上下文栏参照 V1、V2 的强玻璃，侧栏与输入区使用半透明表面，独立滚动区保留可读底色。状态通过文字和颜色共同表达。
- 顶栏沿用 V1、V2 的小鱼品牌标、半透明壳层、细边线与内高光。壳层使用 20px 模糊和 165% 饱和度，工具、设置和连接胶囊通过底色与边线体现层级。三态主题保留 V2 的渐变色圆点和选中外圈。
- 标题与正文统一使用带中文回退的无衬线字体。主标题在桌面约 30px，靠字重建立层级。正文留足行高，长网址和长文本可以换行，短说明使用 12–14px。
- 桌面恢复初版 A 图标轨、三行会话条目、横贯主区与右栏的上下文栏、中央主会话及右侧产物。1440px 下左侧约 316px，右侧约 300px，标题、消息与输入区共用中央阅读宽度。900px 起使用抽屉，760px 和 520px 调整阅读与触控密度。
- 用户气泡靠右，左侧独立名称列为以后显示自定义名字预留宽度。具身智能体气泡靠左，角色名和时间显示在气泡内。主会话标题区域呈现当前状态、可用的 Ticket 与目标版本、Worker、任务和待审批入口。执行记录沿用初版 A 紧凑的状态、摘要与时间三列。输入区在滚动内容下方占据独立空间。
- Worker 协作列表进入中央只读详情。对话沿用消息气泡，执行记录与能力各有入口，返回列表恢复到原选中的 Worker。
- 按钮、筛选、选中列表、输入区和原生弹层采用统一焦点样式。产物容器优先展示内容与打开入口。暂无产物、加载和读取失败保留稳定位置。
- 会话中呈现实际 Agent 名称和自然表达。原始执行代码、参数和日志归到按需查看的位置。动效用于开合与状态变化，尊重系统减少动态效果设置。
