## 2. 主要问题清单（按严重程度）

### P0 — 阻断（Agent 承诺无法被验证）

**P0-1 `worker/ticket` 状态在 UI 完全不可见**
- 证据：UI 只有三处 OWA 痕迹（`main.js:1273-1287` 主会话按钮、`1294-1308` 追加版本、`1062-1083` 产物下载）；无 Worker 列表/进度/并发/归属/waiting_peer；后端 `/omniweave/sessions/{id}/tickets` 投影 UI 从未调用。
- 影响：产品定位是"主会话统一呈现 Worker"，但界面只呈现 Router run；后台 Worker 既看不见也停不掉（run 终态后 cancel 按钮禁用 `1592-1593`，Worker 可能仍在跑）。
- 方向：主会话内新增「任务卡 + Worker 状态条（idle/running/waiting/blocked/done/failed）+ 归属与并发数 + 以根 ticket 停止」。

### P1 — 重大问题

**P1-1 审批卡用 JSON 说明风险，且离页即消失**
- 证据：`main.js:1390-1458` 审批卡 `需要确认：{tool}` + 缩进 JSON；同一审批渲两处 DOM（浮层 absolute 覆盖消息 + 右栏待办页签），1 秒内可从两处提交冲突决定；浮层只有「允许本次/拒绝」；过期只能重新发起；无 autofocus；`#approvals` 每秒 `replaceChildren`，读屏反复播报。
- 影响：唯一高危决策点要求用户读机器参数猜后果；离开页面即丢决策上下文。
- 方向：单审批对象、锚定 turn、三段式人话（会发生什么/影响范围/可撤销性/费用）+ 参数表（JSON 折叠）、默认焦点、延期/稍后、全局待办徽标。

**P1-2 停止/失败/中断无恢复闭环，无输入队列**
- 证据：取消运行按钮无确认、无"正在取消"、可连点（`main.js:1504-1508,2105-2109`）；停止后无 Resume；无 run/turn 级 Retry（`1536-1538` 只追加文字）；运行中发送直接抛错（`2042`），无排队/暂停/恢复；composer 无队列 UI。
- 影响：长任务被打断=重述一遍；排队输入意图丢失；失败不可定点重试。
- 方向：状态模型（Waiting/Working/Approval/Stopped/Error/Partial/Queue paused）+ Stop→Resume→Retry（对象级、写明重跑范围）+ 队列条目（编辑/删除/重试/阻塞）。

**P1-3 执行时间线不完整、键盘不可达**
- 证据：调用链 60 步硬截无提示（`main.js:508`）；失败仅图标+色，错误文本藏在展开层、无 exit code（`497-503`）；行与链开关是 `div`（`576-587`）；总耗时是各行相加非墙钟（`1216-1232`）；成本只在右栏档位面板。
- 影响：排障与审计成本高；键盘用户无法查看过程。
- 方向：Timeline 组件（墙钟/阶段/工具/失败原因/exit code/成本），行可聚焦 `button[aria-expanded]`，截断显式提示。

**P1-4 导航靠记忆：26 个无标签图标 + 双份导航**
- 证据：`nav[aria-label=工作台]` 26 个 `rail-btn`（34×32），分组标题 `.nav-group` 被 `clip-path:inset(50%)` 视觉隐藏（`workbench.css:351`）；非对话页再套 196px `.settings-rail`（25 项，`settings-rail.js`），与左 rail 重复；运行时测量：390 宽时 rail `scrollWidth=1044` vs `clientWidth=390`，横向滚动的 26 图标条。
- 影响：低频页面只能 hover 试；390 宽度下导航不可用；两套导航心智负担。
- 方向：单一导航模型（高频 5–7 项 + 分组可展开/可搜索），设置类二级导航只在设置中心保留并带标签；390 用抽屉/底部面板。

**P1-5 读屏与键盘退化（live region 全量重播）**
- 证据：`#messages` `aria-live="polite"` + 整表 `replaceChildren`（`index.html:338`、`main.js:1011,1596`）；`#approvals` 每秒重建；会话行 `role=button` 无 Enter/Space（`1332-1358`）；主题 `role=radio` 无方向键（`index.html:22-49`）；无 skip link。
- 影响：读屏用户被整段历史反复打断；键盘用户打不开会话。
- 方向：局部 status 播报、会话行改 `<button>`/补键位、radio roving tabindex、skip link、焦点管理。

### P2 — 次要（可绕开但拉低质感）

**P2-1 层级不可辨 + 装饰性 AI 皮肤**
- 证据：运行时表面取样（浅色）：header/rail `#fff/68%`、panel `#fff/84%`、内容区透明、页面底为网格渐变；暗色下左/中/页面底同为 `rgb(15,16,17)`（`04/10` 页内容区与页面底 `rgb(7,8,9)` 相同），主内容无独立表面。detector：`codex-grid-background`、`dark-glow`×2、`pulsing-dot`×2、`gradient-text`、`repeating-stripes-gradient`、`nested-cards`。
- 影响：看起来像模板/原型而非成熟产品；浅色主题"糊成一片"，深色主题分不清层。
- 方向：删掉网格/发光/脉冲/渐变文字；表面阶梯 ΔL≥3–4%，inset 比底更暗；玻璃只留壳层一档。

**P2-2 双 H1 / 标题层级倒置 / 无页面模板**
- 证据：`v2/index.html` 21 个 `<h1>`、24 个 `<h2>`；`#page-title` 16px，内容区 H1 走 UA 默认 30–32px（04/05/10/19/20 实测）；23 个非对话页共用"页头 16px 标题→设置 rail→30px 同名标题→长散文→满宽表单"。
- 影响：屏幕阅读器轮廓混乱；页面像后台 CRUD。
- 方向：一页一个 H1（页头）；4 个页面模板（对话/监控台/表单设置/审计日志）；删内容区重复标题。

**P2-3 行宽失控、数据退化为散文/JSON**
- 证据：配置页正文 x=289→1396，1107px 宽，11–12px 中文约 90–95 字/行；审计页唯一呈现是 1106×550 的 `<pre>` 原始 JSON；能力页用"加粗标签 + `enabled=true·owned=0`"连排；日志时间用 `·` 串成两行长墙。
- 影响：长文难读、状态难扫、审计无法取证。
- 方向：正文 `66ch`；键值对进 DataTable/Timeline；时间/ID/金额 mono + tabular；审计改结构化时间线。

**P2-4 字号过小（系统性）**
- 证据：运行时 1440 页统计：11px×666 个元素、10.5px×426、13px×460、12px×156、16px×2；detector `undersized-ui-text` 248 条、`tiny-text` 9 条、`flat-type-hierarchy`。
- 影响：CJK 在 10.5px 下可读性差；层级靠缩小而非对比。
- 方向：正文 13、最小功能字号 12（11 仅次行 meta，10.5 仅 badge/eyebrow 或取消）；类型阶梯 6 档。

**P2-5 主操作权重失衡（全宽渐变横幅 / 危险同款）**
- 证据：`memory`「保存记忆」全宽 1110px 渐变（04）；`deliveries`「登记插件包」渐变（10/11）；`logs`「重新查询」210px 渐变；`13`「清空暂存」是全宽次按钮；`05`「结束终端及其进程」与「更多会话」同款按钮；`--grad` 上白字仅 1.7:1 风险（现用深墨正确）。
- 影响：一屏多个主操作；危险动作不突出。
- 方向：`.primary` 28–36px 行内、同屏 ≤1；危险动作 `.danger` + 确认 + overflow 菜单；全宽仅 dialog footer。

**P2-6 主题与 token 治理问题**
- 证据：`tokens.css:181-259` 的 19 个 `--v2-*` + 7 个 `--hermes-*` 全站零引用且写在 `[data-theme="light"]` 块内；玻璃三档 264 处引用但实际只有一档可见；`--surface-inset` 与 `--surface-0` 同值（04）；浅色主题 `#fff on #f4f6f8` 边界仅 8–10% 墨线（41）。
- 影响：设计系统"看起来有，实际没生效"；浅色主题不可用。
- 方向：删死 token/死 CSS；玻璃收敛 1 档；补 `--surface-4/-hover/-selected`；浅色单独校验对比。

## 3. 建议的视觉方向

**主方向：Instrument Panel（仪表台）＝ Dark Mode (OLED) × Data-Dense Dashboard + 克制壳层玻璃 + Swiss 栅格排版。**

- 关键词：`低发光` `高密度可扫` `状态驱动` `单一强调色` `树/表/时间线` `一页一标题`。
- 保留：青 `#3ddbd9` / 紫 `#7c8cf8` 作为唯一品牌 seed；等宽字体用于 ID/时间/金额；暗色优先；本地字体。
- 删除：网格背景、零偏移发光、脉冲光点、渐变文字、条纹渐变、嵌套卡片、全宽渐变横幅、装饰性 icon tile。
- 不做的方向：cyberpunk/HUD（括号、扫描线、glow 会直接制造营销感）、SaaS 卡片墙、营销 hero。
- 参考坐标（ui-ux-pro-max 命中）：`Dark Mode (OLED)` + `Data-Dense Dashboard` + `Real-Time Monitor` + `Terminal`；排版走 `Minimalism & Swiss` 网格；玻璃只保留"壳层一档"（glassmorphism 克制版）。

**视觉语言三句话**：
1. 表面是分层的炭黑仪表盘，不是发光的玻璃卡片墙；
2. 强调色只出现在"主操作 / 选中 / 进度"三处；
3. 状态用结构化徽章与时间线表达，不用颜色和 JSON 说话。

## 4. 完整 UI 重构计划

### 4.1 目标架构（前端内部，不动内核/DB/API）

```text
App shell
├─ Global rail（54–224px，可展开显示标签，单一导航源；390 → 抽屉）
├─ Page shell（唯一 H1 页头 + 页级 actions + 可选 Tabs）
│  ├─ T1 对话：Sessions(260) | Thread(760–820) | Inspector(320，可折叠)
│  ├─ T2 监控台：Toolbar + DataTable/Timeline/Badge（内容最大 1100–1200）
│  ├─ T3 表单设置：单列 ≤720 + 分组卡 + sticky 保存条
│  └─ T4 审计：左侧时间线 + 右侧 Inspector（键值对）
└─ 全局层：命令面板（⌘K）、审批中心徽标、Toast
```

### 4.2 迁移策略（低风险，分批）

1. **只动 `web/ui/`**：V2 样式层是 `ui/v2/workbench.css` + token 层；不重写 `main.js` 业务逻辑，先做"壳与组件替换"。
2. **停用 V1 冻结副本**：`ui/v2/v1/*.css` 是 V1 拷贝，重构期间改为"V2 自有基线 + 组件层"，冻结副本只作回滚参照（不再双处同步）。
3. **页面按模板分批迁移**：先 4 个高频页（chat/settings/memory/logs），再批量套 T2/T3 模板，最后收尾 26 页。
4. **每一步保留功能与回滚**：每批改动前后 4 视口×2 主题截图；`?v=` 版本串按纪律递增；跑现有 UI 守卫测试。
5. **状态模型先行**：先把 `conversation-state` 单一状态源与审批/队列对象契约定下来，再动视觉，避免"好看的皮 + 分散布尔"。
6. **验收门槛**：detector 零 P0/P1；正文对比度 ≥4.5:1；单页 `backdrop-filter` ≤3；一页一个 H1；最小功能字号 ≥12；390 无横向溢出；键盘主路径可完成。

### 4.3 风险

- V2 无布局回归基线（现仅 pytest 契约），重构需先补截图基线，否则改动不可控。
- 26 页面模板化可能与"页面内原生面板（能力诊断/任务/MCP/项目索引）"冲突，需先统一容器边界。
- 审批卡移入 turn 流会改动 DOM 位置与轮询重建逻辑，需要状态迁移与焦点恢复配套。

## 5. 设计系统方案（Design System）

### 5.1 Token 层（在 `web/ui/tokens.css` 单源内演进）

**保留**：seed 青/紫、ok/warn/danger、字体、圆角、`--rail-w`、`--ease-out`。
**新增/改造**：
- 表面：`--surface-0..4`（每级 ΔL≥3–4%）、`--surface-hover`、`--surface-selected`；`--surface-inset` 改为**比 surface-0 更暗的实色**。
- 边线：`--line-divider`（主分隔）、`--line-focus`；`--line-3` 仅装饰。
- 语义：`--info(-bg/-bd)`（中性蓝灰）、`--unknown(-bg/-bd)`（虚线/斜纹 + 文本）、`--running/--queued/--paused`。
- 排版：`--fs-display(20)/--fs-title(16)/--fs-section(14)/--fs-body(13)/--fs-secondary(12)/--fs-caption(11)`；`--lh-body 1.65`；`--fw-regular/medium/semibold/bold`（400/500/650/700）。
- 布局：`--measure-body 66ch`、`--measure-wide 96ch`、`--row-h 32/36/40`、`--z-sticky/drawer/dialog/tip`、`--dur-fast/base/slow`＝120/180/240。
- 玻璃：收敛为 `--glass-shell`（仅 rail/header/dialog）；删除 mid/weak 两档与死 token（`--v2-*`/`--hermes-*`/`--terminal-bg` 等）。

### 5.2 组件层（components.css）

新增：`StatusBadge`（idle/waiting/running/approval/stopped/error/partial/unknown/queued 九态，图标+文本+色）、`Timeline`（时间列+状态点+折叠详情+wall-clock+成本）、`ApprovalCard`（人话摘要+目标/范围/风险/费用+允许/拒绝/延期+证据折叠）、`QueueList`（有界、计数、编辑/删除/重试、失败阻塞）、`DataTable`（sticky 表头、行高 36、tabular、列限宽、行状态条、空/加载/错误态）、`Inspector`（key-value 分组 + 可复制 mono 值）、`Meter`（上下文/预算：中性填充 + 阈值色）、`Toolbar`、`CodeBlock`、`Kbd`、`CommandPalette`。

### 5.4 交互契约（agent-product-ui-ux 落地）

- 单一状态模型（discriminated `conversationState`）驱动：信号、主操作、恢复范围。
- Working 可 Stop；Stopped 保留草稿/队列/位置，显式 Resume；Error 对象级 Retry（写明重跑范围）；Partial 先列失败对象；Queue paused 不静默跳过。
- 审批：单对象、锚定 turn、默认焦点安全、允许/拒绝/延期、离页进入全局待办。
- 滚动：follow zone 24px 起；用户上滚后显示回底但不抢滚动；per-thread 位置。
- 焦点：层关闭还焦、Escape 分层、活动行可聚焦；live region 只播报状态摘要。
- 工具工作区：compact launcher → 激活工具（tabs + canvas + filterable tree）→ 关闭还焦；不做单面板工具平台。
