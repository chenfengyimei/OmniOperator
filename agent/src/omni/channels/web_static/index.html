                  B站与转写
                  
        
                  想让小鱼帮你搬运 B 站视频，得先给它一个「登录凭证」——就相当于告诉它「这个账号是我」。
                  没有凭证也能用，但只能看到公开内容，字幕和音频大概率拿不到。
                  
        
                  
          
                  凭证怎么拿
                  
          
                  先在浏览器里登录 B 站，按 F12 打开开发者工具 → Application（应用）→ Cookies → bilibili.com，找到下面几项，把值复制过来。
                  只有 SESSDATA 是必需的；另外两项留空也能跑，但发评论、点赞之类的操作会失败。
                  
        
                  
        
                  
        
                  
        
                  
        
                  
        
        
                  语音转文字
                  
        
                  视频没有字幕时，小鱼会把声音转成文字再理解。模型越大越准，也越慢越吃内存。

                  小鱼用浏览器时，每一下点击、每一次填表都会先问你；每天还有次数上限，防止它一个人点个不停。

                  跑过的记录
                  
        
                  成功失败都记，最近的留在上面。
                  
        
                  
        
                  还没发出去的结果
                  
        
                  QQ 掉线的时候结果不会丢，先存着，等连上自动补发。
                  标着「不知道发没发出去」的那几条不会自动重发——万一对方其实收到了，重发就成了两条。先确认一下再手动点。
                  
        
                  
      
                  
      
                  
        
                  花了多少钱
                  
        
                  每次跟模型说话都要花钱，这里能看到明细。设了每日上限的话，超了它就不往下跑了，会先来找你。
                  
        
                  
        
                  这几天都花在哪了（最近 7 天）
                  
        
                  
        
                  最近几十次调用
                  
        
                  
        
                  各个模型会什么
                  
        
                  没在这张表里登记过的能力，小鱼不会去用——所以如果某个模型明明会看图却不认，多半是这里漏了。
                  
        
                  
      
                  
      
                  
        
                  扩展能力
                  
        
                  
          扩展是给小鱼「加装新本事」的东西——装上之后它就能用别人做好的工具，比如查资料库、读表格、连你公司里的系统。
                  
          每个扩展装好会自己连上，你可以随时点「看看能做什么」让它报一遍家底。
        
                  
        
                  
          
                  安全规则只有一条
                  
          
                  只看不改的操作，小鱼自己就能用，不打扰你；凡是会改动东西的，一定先问你。至于哪些算安全，由小鱼按你确认过的清单判断——扩展自己说「我很安全」是不作数的。
                  
        
                  
        
                  
      
                  
      
                  
        
                  Agent 与文件
                  
        
                  在这里统一管理 Agent 空间根目录、记忆/技能/产物等路径，以及当前公开文件区。目录修改只影响下次启动，旧数据不会自动搬移。
                  
        
                  
          
                  路径与文件安全
                  
          
                  文件区只开放当前 Agent 的公开目录；文本预览有大小上限，二进制文件只显示元数据；上传、建目录和备份都需要明确操作。
                  
        
                  
        
                  
          
        
                  
      
                  
      
                  
        
                  关于
                  
        
                  OmniOperator · 像人一样生活在平台里的智能体。
                  
        
                  
          
                  它是什么
                  
          
                  它住在你这台电脑上，有自己的号码、自己的记忆，会慢慢学会你交代过的事。你说过的话它会记住，下次不用重复；重复的活儿它会自己编成技能，越用越顺。
                  
        
                  
        
                  
          
                  它不会自己做的事
                  
          
                  花钱、发布、群发、加好友——这四件事它必须经过你点头。就算它觉得再合理，也会停下来等你确认。
                  
        
                  
        
                  维护与数据
                  
        
                  诊断只读取状态，不启动服务。备份会包含私人记忆；配置中的密钥会被脱敏，浏览器登录态不会包含。
